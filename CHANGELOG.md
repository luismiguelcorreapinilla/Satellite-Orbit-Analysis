## [1.0.0] - 2026-07-22

### Added

- Initial public release.
- Satellite orbit propagation using TLE data.
- Keplerian and SGP4 orbital propagation workflows.
- Ground-track visualization over Colombia.
- Satellite coverage analysis for major Colombian cities.
- Interactive Streamlit application.
- Scientific documentation and repository restructuring.
- GeoSpatial Intelligence Lab branding.
- MIT License.
- CITATION.cff for scientific citation support.
- Project documentation.
