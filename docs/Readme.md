# Documentation

This directory contains the technical and scientific documentation for the **Satellite Orbit Analysis over Colombia** project.

The documents provide the theoretical background, methodology, and references required to understand and reproduce the complete workflow implemented in this repository.

## Contents

| Document | Description |
|----------|-------------|
| **overview.md** | General description of the project, objectives, and applications. |
| **methodology.md** | Step-by-step description of the scientific workflow and data processing pipeline. |
| **orbital_mechanics.md** | Introduction to orbital mechanics, TLE data, SGP4 propagation, and ground tracks. |
| **references.md** | Scientific references, datasets, software libraries, and external resources used throughout the project. |

## Purpose

The documentation complements the Jupyter notebooks and source code, providing the scientific context behind the implemented algorithms and analyses.
